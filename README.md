## Como Usar o Google Dorks Pro

### 1. Busca Avançada
O Google Dorks Pro utiliza técnicas avançadas de busca para encontrar leads qualificados. Basta descrever seu negócio e o tipo de leads que procura no campo de busca.

### 2. Filtros Google Dorks
Selecione os filtros mais relevantes para sua busca. Os filtros utilizam operadores avançados do Google para encontrar informações específicas como e-mails, telefones, documentos e muito mais.

### 3. Palavras-chave
O sistema extrai automaticamente palavras-chave relevantes da sua busca. Você pode adicionar mais palavras-chave manualmente para refinar ainda mais os resultados.

### 4. Histórico de Buscas
Suas buscas são salvas automaticamente para referência futura. Você pode acessar e reutilizar buscas anteriores a qualquer momento.
